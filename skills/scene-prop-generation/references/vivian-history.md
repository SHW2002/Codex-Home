## 生成方式与授权背景

历史用户明确要求缺少素材可以AI生成，使用其指定服务中的 `gpt-image-2.5`，最高档质量；当时通过 `imagegen` 技能附带CLI使用 `quality=high`，而不是另写请求客户端。

该标识是历史指定服务使用的模型名，不据此宣称它是官方通用模型或所有工具都支持。再次在这个项目里生图时，保留用户的模型与质量偏好；先核实当前CLI和服务支持的参数，遇到不支持应说明具体限制，不静默改成其他模型或供应商。

服务URL和Key从旧会话指向的本地环境配置读取；本技能不包含密钥，也不固化未核实的配置路径。当前任务若只要求整理技能、写提示词或查看候选，不因历史授权自行发起新一轮付费生成。

用户在创建本技能时进一步明确：技能需要写明API、URL、模型与质量要求，并将通过本地 `.env` 提供接口配置。因此 `gpt-image-2.5 / high` 已提升为本个人技能的默认要求，凭据加载采用 [API与.env配置](api-config.md)，不再仅作为本项目历史参考。

## 已验证的风格与返修原因

| 用户反馈或问题 | 最终处理与可复用经验 |
| --- | --- |
| 顶部物件太亮、太写实 | 用真实Home家具/柜子截图作为风格参考重新编辑；粗描边、简洁色块，去掉写实木纹、锈蚀和发亮金属 |
| 缺光的屋顶应该接近黑色 | 改成蓝紫近黑剪影，只有底边有微弱室内反光；灯具熄灭，实体Alpha不随变暗降低 |
| 屋架右侧悬空 | 补连续角撑立柱与横梁，描述连接关系，放进同一屋架视差根保持接点重叠 |
| 吊挂结构看似浮空 | 在贴图上增加连接上方梁的吊绳，并让绳端能藏在梁后 |
| 悬梁遮住通往大街的门 | 复用原梁图拆成左右两块，中间保留门口及相机运动所需空间 |
| 门口梁断面切得生硬 | 复用原图包边、螺栓和斜撑收口，而不是重新生成整套屋架 |
| 黑色遮挡物漏出背景 | 区分深色与半透明；只修复确定属于实体内部的近不透明像素，保留轮廓抗锯齿 |
| 出门蒙太奇显得像黑幕 | 使用实际建筑前景掠过遮镜，在完整遮挡时切换，保持两侧轮廓和颜色一致 |
| 幕布或飞机遮住角色 | 检查临时覆盖组、主体排序与站位；揭幕后恢复场景原有排序，不把整架飞机永久置顶 |

初版提示词曾同时包含“旧木纹、磨损、金属接头、边缘高光”等描述，后续证明会把屋架推向写实和过亮；重新制作时直接使用最终风格，不照抄初版。

## 贴图种类

- 屋架：`RoofFascia`、`WallPier`、`RoofCornerSupport`、`RoofCrossJoist`。
- 吊挂：`CeilingCables`，后续改用带吊绳的 `CeilingSuspension`。
- 门口梁：`RoofBeamLeft/Right` 与 `RoofJoistLeft/Right`，由既有图裁切及修端，完整梁图仍供专用遮镜使用。
- 飞机盖布：`Assets/Art/Sprites/Airplane/Story/AircraftCover.png`，以实际飞机透明渲染图锁定鼻部朝下、机尾朝上的视角。
- 掉落道具：`LooseScrew.png`，用粗描边、大头短杆保证小尺寸识别。

顶部Sprite沿用项目锚点约定，并按父级缩放补偿世界大小。原图裁切得到的实际尺寸可能不同于API请求尺寸，导入时使用真实尺寸。

## 本项目接入约束

- 任何Unity编辑器操作都通过Agent Bridge，先按当前会话协议发现命令，不凭旧缓存直接发请求。
- 正常地面用Floor层，阴影用Shadow层，普通物件按既有Default层与Y轴规则；阴影组启用SortAtRoot，光照层范围同步遵守当前设计规范。
- 相接屋架共用视差运动；近柱和两侧蒙太奇屋檐按用途独立，演出结束恢复隐藏状态。
- 玩家看飞机、拉布、拾取零件时保持可读性，但不因此移动或隐藏千斤顶、拉杆等原场景摆设。
- 项目要求不运行游戏自测；使用编辑器刷新、编译和场景副本采样，临时制作脚本用完删除。新的明确用户要求优先于旧会话流程。

重新生成时只继承仍适用的风格和工作方式；不要把历史视差系数、坐标或分镜时间当作新任务的固定参数。
