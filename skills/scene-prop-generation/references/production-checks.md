# 透明贴图处理与场景接入

## 像素与Alpha

- 检查文件的实际尺寸和通道；请求了某尺寸、PNG或“transparent”不证明返回结果真的符合。
- 透明背景必须有实际Alpha；画在图里的棋盘格、白底和黑底都不算透明。
- 在浅色、深色及实际场景底色上查看边缘，检查白边、黑边、残留背景与漂浮像素；再缩到最终使用大小复查。
- 用主体轮廓而非整张画布判断实体区域；真正的孔洞和设计的透光玻璃可以保留透明，木梁、布罩等遮挡实体应保持不透明。
- 不要对全部像素直接二值化Alpha，否则吊绳和抗锯齿边缘会断裂。仅在有漏光证据时，将确认属于实体内部且接近不透明的像素修复为255。
- 清理低Alpha杂点时检查细绳、灯链和小螺丝轮廓，不能按统一阈值把这些有效细节抹掉。

裁切可以使用Alpha非空包围盒加适量边距，但先确认没有需要对齐的固定画布、动画锚点或伸出画布的连接绳。记录原尺寸、裁切矩形和最终尺寸，保证后续变体沿用一致对齐方式。

## 世界尺寸、Pivot与父级缩放

不要把最终贴图像素尺寸直接当作世界尺寸，也不要给所有新图统一使用项目中某个偶然出现的PPU。

未旋转且按轴缩放时，世界宽度约为：

`worldWidth = spriteRectPixelWidth / pixelsPerUnit × abs(lossyScale.x)`

父级有旋转、非均匀缩放或网格变形时，使用变换后的Sprite角点/实际边界检查。需要贴合建筑时，优先保持合理PPU与场景世界尺寸，不靠反复拖缩放猜位置。

- 地面道具通常把Pivot放在接地点，使Y轴排序与场景一致；具体沿用相邻同类物件的约定。
- 建筑补件可把锚点放在连接处。裁切或更换透明留白后，需要补偿位置，不能只保留旧归一化Pivot数值。
- 覆盖物需要对齐主体时，共用画布/参照点或保留明确的裁切偏移，再检查世界轮廓。
- 记录父节点缩放；“按像素算好了但进场景过大”的问题常来自继承的缩放。

## 光照、材质和阴影

对比实际场景使用的Sprite材质、颜色乘数与Light2D影响范围。新增背光图优先与场景既有材质一致；图片已经压暗时，需检查引擎里再次压暗后是否丢失必要轮廓。

前景近黑是照明意图，不应通过降低Renderer Alpha实现。是否使用受光材质取决于项目，不为让图变黑擅自替换整套渲染方式。

如果场景把阴影独立排序，生成主体时避免外部投影，并让阴影继续走既有层级。《薇薇安的飞机》的具体排序规则见项目案例，不将它硬编码到其他项目。

## 建筑连接与视差

| 检查点 | 通过条件 |
| --- | --- |
| 梁柱接点 | 有足够重叠，端部承接合理，镜头运动后不露缝 |
| 吊挂物 | 绳/支架连到有效上方结构，固定端藏在梁后 |
| 门洞缺口 | 当前镜头和游戏相机范围内门、出口标识与玩家均可见 |
| 梁端 | 有自然端盖、包边、连接件或支撑，不呈现突兀直切 |
| 屋架整体运动 | 相接部件保持相对位置；不同视差层之间预留足够交叠 |
| 普通游玩 | 转场专用前景不会持续遮挡人物与门 |

相连屋架通常共用一个视差根，近柱与转场屋檐可以独立分层。视差实现应从稳定基准计算，重复采样、切镜或倒拖不能累积漂移；这里只定义验收目标，不为单纯生成图片的任务强行新增运行时代码。

蒙太奇遮镜应在完整遮挡时切换，比较切镜前后画面的覆盖范围、轮廓、颜色和运动方向；黑色像素之外还需检查Alpha。指定遮挡只在演出区间启用，停止预览后恢复正常状态。

## Unity接入与检查边界

先读取项目AGENTS.md和设计规范。项目有Agent Bridge时，按其当次发现的命令schema及串行请求协议执行；不把某次会话的命令名和缓存版本当作永久接口。

导入外部PNG后通过编辑器设置Sprite类型、PPU、Pivot、材质和引用，替换现有资源时保留GUID；需要修改场景或Prefab的引用也通过编辑器完成。临时Editor脚本保持简洁，不复用旧builder重建无关资源，用后删除。

编辑器采样可检查：镜头起止、门口、揭幕、切镜前后、停止和倒拖。采用场景副本或可恢复状态，避免留下实际Home场景的脏标记或额外对象。没有运行游戏时，报告“编辑器采样/渲染验证”，不称为最终游戏录屏。

检查普通物件排序与场景Y轴规则是否一致，覆盖布是否既盖住主体又按站位正确显示角色；不要使用永久置顶覆盖所有角色的方式掩盖排序错误。不要为了画面好看删除、隐藏或移动拉杆、千斤顶等无关摆设。

## 保存记录

每个交付物保留足以复现的简短记录：参考图身份、最终提示词、实际工具和模型标识、质量/尺寸请求、实际返回尺寸、透明度与裁切处理、目标资源路径、PPU/Pivot，以及验证画面的位置。

API Key、认证头、含认证参数的URL和本地环境文件内容不进入记录或Git。原始生成图保留在工作输出目录，正式项目只导入选定结果；提示词和制作说明放在项目已有文档分类下。
